This thesis presents the design and implementation of a digital ordering and services system for short-term rental accommodations. The system is built as a multi-tenant SaaS platform whose main point of contact with the guest is a kiosk application on an Android tablet installed in the property. Guests can browse the product catalogue, place orders and pay on the same device, through an external payment provider, without installing an application or creating an account. Owners manage their properties, product catalogue and orders through a web panel, while the platform serves many independent owners at the same time and keeps each owner's data isolated.

The architecture follows the principles of Clean Architecture and the Port/Adapter pattern: the core does not depend on frameworks, and the business logic reaches external services only through interfaces. All the code is written in Kotlin, and Kotlin Multiplatform (KMP) lets the backend (JVM), the Android kiosk application and the web panel (WebAssembly) share the domain model and the DTOs. The backend was built with Ktor and JetBrains Exposed, and the database follows a schema-per-tenant strategy in PostgreSQL: each owner's data lives in its own schema, which a single, central point in the code selects for every transaction. The web panel was developed with Compose Multiplatform, compiled to wasmJs.

The outcome is a working, integrated prototype that covers the hierarchy platform → owner → property → device → guest. The system includes JWT authentication with role-based access control (RBAC), automated device activation through a QR code, an order state machine, connections to real external services (email over SMTP, company lookup in a public company registry and address search), emulated delivery and payment services, and a central audit log. The implementation suggests that Kotlin, through KMP, can carry a system that spans server, Android and browser in a single language.

**Keywords:** multi-tenant SaaS, kiosk, Android, Kotlin Multiplatform, Clean Architecture, REST API, PostgreSQL
