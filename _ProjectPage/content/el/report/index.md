## Περίληψη

Η παρούσα εργασία παρουσιάζει τον σχεδιασμό και την υλοποίηση ενός ψηφιακού συστήματος παραγγελιών και υπηρεσιών για καταλύματα βραχυχρόνιας μίσθωσης. Το σύστημα υλοποιείται ως πλατφόρμα multi-tenant SaaS, με κύριο σημείο επαφής για τον επισκέπτη μια εφαρμογή kiosk σε Android tablet εγκατεστημένη εντός του καταλύματος. Οι φιλοξενούμενοι μπορούν να περιηγηθούν στον κατάλογο προϊόντων, να υποβάλουν παραγγελίες και να πραγματοποιήσουν πληρωμές απευθείας από τη συσκευή, χωρίς να απαιτείται εγκατάσταση εφαρμογής ή δημιουργία λογαριασμού. Οι ιδιοκτήτες καταλυμάτων διαχειρίζονται τα ακίνητα, τον κατάλογο προϊόντων και τις παραγγελίες τους μέσω web panel, ενώ η πλατφόρμα εξυπηρετεί ταυτόχρονα πολλούς ανεξάρτητους ιδιοκτήτες με πλήρη απομόνωση δεδομένων.

Η αρχιτεκτονική του συστήματος βασίζεται στις αρχές της Clean Architecture και του Port/Adapter pattern, διατηρώντας την επιχειρησιακή λογική αυστηρά ανεξάρτητη από υποδομές και εξωτερικές υπηρεσίες. Το σύνολο του κώδικα αναπτύσσεται σε Kotlin, αξιοποιώντας το Kotlin Multiplatform (KMP) για την κοινή χρήση του domain model και των DTOs μεταξύ backend (JVM), εφαρμογής Android kiosk και web panel (WebAssembly). Το backend υλοποιήθηκε με Ktor και JetBrains Exposed, ενώ η βάση δεδομένων υιοθετεί στρατηγική schema-per-tenant σε PostgreSQL, επιτυγχάνοντας δομική απομόνωση στο επίπεδο του συστήματος διαχείρισης βάσεων δεδομένων. Το web panel αναπτύχθηκε με Compose Multiplatform με στόχο μεταγλώττισης wasmJs.

Τα αποτελέσματα της εργασίας περιλαμβάνουν ένα πλήρως λειτουργικό, ολοκληρωμένο πρωτότυπο που καλύπτει την ιεραρχία πλατφόρμα → ιδιοκτήτης → ακίνητο → συσκευή → φιλοξενούμενος. Το σύστημα ενσωματώνει ταυτοποίηση JWT και έλεγχο πρόσβασης βάσει ρόλων (RBAC), αυτοματοποιημένη ενεργοποίηση συσκευών μέσω QR code, μηχανή καταστάσεων παραγγελιών (order state machine), προσομοίωση εξωτερικών υπηρεσιών διανομής και πληρωμών μέσω emulated adapters, καθώς και κεντρικό audit log. Η εργασία τεκμηριώνει εμπειρικά ότι η Kotlin, μέσω του KMP, παρέχει μια αξιόπιστη βάση για την ομοιόμορφη ανάπτυξη ενός σύγχρονου, κατανεμημένου συστήματος λογισμικού.

**Λέξεις-κλειδιά:** multi-tenant SaaS, kiosk, Android, Kotlin Multiplatform, Clean Architecture, REST API, PostgreSQL
