## Γλωσσάρι Ξενικών Όρων και Ακρωνυμίων

Ο Πίνακας Β.1 συγκεντρώνει τους ξενικούς όρους που χρησιμοποιούνται στο κείμενο, με την ελληνική τους απόδοση και μια σύντομη επεξήγηση. Ο Πίνακας Β.2 συγκεντρώνει τα ακρωνύμια, με την πλήρη μορφή τους και μια σύντομη επεξήγηση.

### Β.1 Ξενικοί όροι

**Πίνακας Β.1: Ξενικοί όροι, ελληνική απόδοση και επεξήγηση**

| Ξενικός Όρος | Ελληνική Απόδοση | Επεξήγηση |
|---|---|---|
| Access token | Διακριτικό πρόσβασης | Βραχύβιο token που συνοδεύει κάθε αίτημα και αποδεικνύει την ταυτότητα του χρήστη. |
| Acquirer | Φορέας πληρωμών (αποδέκτης) | Ο φορέας που επεξεργάζεται και εγκρίνει τις πληρωμές με κάρτα για λογαριασμό του εμπόρου. |
| Adapter | Προσαρμογέας | Υλοποίηση ενός port για μια συγκεκριμένη τεχνολογία ή εξωτερική υπηρεσία. |
| Audit log | Αρχείο καταγραφής ενεργειών | Χρονολογική καταγραφή των ενεργειών των χρηστών, για έλεγχο και λογοδοσία. |
| Backend | Σύστημα παρασκηνίου | Η λογική διακομιστή, οι βάσεις δεδομένων και η επεξεργασία επιχειρησιακών κανόνων. |
| Browser | Πρόγραμμα περιήγησης | Η εφαρμογή με την οποία ο χρήστης ανοίγει ιστοσελίδες, εδώ και το web panel. |
| Brute force | Εξαντλητική δοκιμή | Επίθεση που δοκιμάζει διαδοχικά πολλές τιμές, π.χ. κωδικούς, μέχρι να βρει τη σωστή. |
| Build | Δόμηση | Η διαδικασία που παράγει εκτελέσιμα αρχεία από τον πηγαίο κώδικα. |
| Bytecode | Ενδιάμεσος κώδικας | Κώδικας για εικονική μηχανή (π.χ. JVM) αντί για τον επεξεργαστή. |
| Clean Architecture | Καθαρή Αρχιτεκτονική | Αρχιτεκτονικό πρότυπο ομόκεντρων επιπέδων με κανόνα εξάρτησης προς το κέντρο. |
| Client | Πελάτης (λογισμικό) | Πρόγραμμα που στέλνει αιτήματα σε έναν server, εδώ το web panel και η εφαρμογή kiosk. |
| Compare-and-set | Σύγκριση και ενημέρωση | Ενημέρωση που εφαρμόζεται μόνο αν η τρέχουσα τιμή είναι η αναμενόμενη, ώστε δύο ταυτόχρονες αλλαγές να μην αλληλοεπικαλύπτονται. |
| Compiler | Μεταγλωττιστής | Πρόγραμμα που μετατρέπει τον πηγαίο κώδικα σε εκτελέσιμη μορφή και ελέγχει τους τύπους. |
| Composable | Συνάρτηση διεπαφής (Compose) | Συνάρτηση που περιγράφει ένα τμήμα της διεπαφής στο Jetpack Compose και στο Compose Multiplatform. |
| Connection pool | Δεξαμενή συνδέσεων | Σύνολο ανοιχτών συνδέσεων με τη βάση που επαναχρησιμοποιούνται από τα αιτήματα. |
| Container | Περιέκτης | Απομονωμένο περιβάλλον εκτέλεσης μιας εφαρμογής μαζί με τις εξαρτήσεις της (Docker). |
| Coroutine | Συρρουτίνα | Ελαφριά μονάδα ασύγχρονης εκτέλεσης που αναστέλλεται χωρίς να δεσμεύει νήμα. |
| Cross-platform | Διαπλατφορμικός | Λογισμικό ή κώδικας που λειτουργεί σε περισσότερες από μία πλατφόρμες. |
| Dashboard | Πίνακας ελέγχου | Οθόνη που συγκεντρώνει συνοπτικά τα βασικά στοιχεία και μεγέθη. |
| Declarative UI | Δηλωτική διεπαφή | Η διεπαφή περιγράφεται ως συνάρτηση της κατάστασης, και το framework ενημερώνει την οθόνη όταν αλλάζει η κατάσταση. |
| Dependency injection | Έγχυση εξαρτήσεων | Οι εξαρτήσεις ενός αντικειμένου παρέχονται εξωτερικά αντί να δημιουργούνται από το ίδιο. |
| Device Owner | Ιδιοκτήτης συσκευής (Android) | Ειδικό δικαίωμα διαχείρισης του Android που επιτρέπει πλήρη έλεγχο της συσκευής, π.χ. για λειτουργία kiosk. |
| Domain | Πεδίο εφαρμογής | Οι έννοιες και οι κανόνες του προβλήματος που λύνει το σύστημα, ανεξάρτητα από την τεχνολογία. |
| Emulated adapter | Προσομοιωμένος προσαρμογέας | Υλοποίηση εξωτερικής υπηρεσίας που αναπαράγει τη λειτουργικότητα τοπικά. |
| Emulator | Εξομοιωτής | Λογισμικό που αναπαράγει μια συσκευή, π.χ. ένα tablet Android, στον υπολογιστή. |
| Endpoint | Σημείο πρόσβασης | Ο συνδυασμός μεθόδου HTTP και διαδρομής στον οποίο απαντά το API. |
| Enum | Απαριθμητός τύπος | Τύπος με προκαθορισμένο σύνολο τιμών, π.χ. οι καταστάσεις μιας παραγγελίας. |
| Epoch milliseconds | Χιλιοστά δευτερολέπτου από την εποχή Unix | Χρονοσφραγίδα ως αριθμός χιλιοστών του δευτερολέπτου από την 1η Ιανουαρίου 1970 (UTC). |
| Firewall | Τείχος προστασίας | Λογισμικό ή συσκευή που επιτρέπει ή απορρίπτει συνδέσεις δικτύου βάσει κανόνων. |
| Foreign key | Ξένο κλειδί | Πεδίο πίνακα που παραπέμπει σε εγγραφή άλλου πίνακα και διατηρεί τη συνέπεια των δεδομένων. |
| Framework | Πλαίσιο ανάπτυξης | Έτοιμη υποδομή λογισμικού πάνω στην οποία αναπτύσσεται μια εφαρμογή. |
| Frontend | Σύστημα προσκηνίου | Το τμήμα της εφαρμογής με το οποίο αλληλεπιδρά άμεσα ο τελικός χρήστης. |
| Garbage collection | Συλλογή απορριμμάτων | Αυτόματη αποδέσμευση της μνήμης που δεν χρησιμοποιείται πλέον. |
| Hash | Σύνοψη κατακερματισμού | Μονόδρομος μετασχηματισμός δεδομένων σε τιμή σταθερού μήκους· χρησιμοποιείται για την αποθήκευση κωδικών και tokens. |
| Health check | Έλεγχος λειτουργίας | Endpoint ή εντολή που επιβεβαιώνει ότι μια υπηρεσία λειτουργεί. |
| Heartbeat (Ping) | Παλμός λειτουργίας | Περιοδικό σήμα ελέγχου διαθεσιμότητας και ενεργής σύνδεσης συσκευής. |
| Hexagonal Architecture | Εξαγωνική Αρχιτεκτονική | Πρότυπο Ports and Adapters για την απομόνωση του πυρήνα από εξωτερικές εξαρτήσεις. |
| Idempotent | Ταυτοδύναμος | Λειτουργία που, αν εκτελεστεί ξανά, δεν αλλάζει το αποτέλεσμα. |
| Kiosk | Σημείο αυτοεξυπηρέτησης | Συσκευή με οθόνη αφής, κλειδωμένη σε μία εφαρμογή, για χρήση από το κοινό. |
| Kiosk mode | Λειτουργία περιπτέρου | Κλείδωμα συσκευής σε συγκεκριμένη εφαρμογή πλήρους οθόνης χωρίς πρόσβαση στο OS. |
| LockTask mode | Λειτουργία κλειδώματος εργασίας | Εγγενής μηχανισμός του Android για το κλείδωμα της συσκευής σε μία εφαρμογή. |
| Log | Αρχείο καταγραφής | Τα μηνύματα που καταγράφει μια εφαρμογή κατά τη λειτουργία της, για διάγνωση προβλημάτων. |
| Loopback | Διεπαφή επιστροφής | Η διεύθυνση δικτύου του ίδιου του υπολογιστή (localhost), μη προσβάσιμη από άλλες συσκευές. |
| Middleware | Ενδιάμεσο λογισμικό | Στάδιο επεξεργασίας από το οποίο περνά κάθε αίτημα πριν φτάσει στον κώδικα που το εξυπηρετεί. |
| Migration | Μετάπτωση σχήματος | Ελεγχόμενη αλλαγή της δομής της βάσης από μία έκδοση στην επόμενη. |
| Module | Λειτουργική μονάδα | Αυτοτελές τμήμα του έργου με δικό του κώδικα και εξαρτήσεις. |
| Monorepo | Ενιαίο αποθετήριο | Στρατηγική αποθήκευσης πολλαπλών σχετιζόμενων υποέργων σε ένα κοινό αποθετήριο. |
| Multi-tenancy | Πολυμίσθωση | Αρχιτεκτονική εξυπηρέτησης πολλαπλών ανεξάρτητων πελατών από μία ενιαία υποδομή. |
| Nullable | Με δυνατότητα κενής τιμής | Πεδίο ή τύπος που επιτρέπει την τιμή null, δηλαδή την απουσία τιμής. |
| Onboarding | Ένταξη | Η εγγραφή και η αρχική ρύθμιση ενός νέου ιδιοκτήτη στην πλατφόρμα. |
| Plaintext | Μη κρυπτογραφημένο κείμενο | Δεδομένα που μεταδίδονται ή αποθηκεύονται χωρίς κρυπτογράφηση. |
| Plugin | Πρόσθετο | Αυτοτελές τμήμα που προσθέτει μια λειτουργία σε ένα framework ή εργαλείο. |
| Polling | Περιοδική ερώτηση | Ο client αποστέλλει αιτήματα στον server σε τακτά διαστήματα για να ελέγξει αν υπάρχουν αλλαγές. |
| Port | Θύρα | Στην αρχιτεκτονική: interface του domain που ορίζει τι χρειάζεται ο πυρήνας από τον έξω κόσμο. Στα δίκτυα: ο αριθμός στον οποίο ακούει μια υπηρεσία. |
| Race condition | Συνθήκη ανταγωνισμού | Σφάλμα που εμφανίζεται όταν το αποτέλεσμα εξαρτάται από τη σειρά ταυτόχρονων λειτουργιών. |
| Rate limit (rate limiting) | Όριο ρυθμού αιτημάτων | Όριο στον αριθμό των αιτημάτων που δέχεται ο server ανά χρονικό διάστημα, π.χ. 20 ανά λεπτό· η υπέρβασή του απαντάται με 429 Too Many Requests. |
| Reflection | Ανάκλαση | Επιθεώρηση και χρήση κλάσεων και μεθόδων κατά την εκτέλεση του προγράμματος. |
| Refresh token | Διακριτικό ανανέωσης | Μακρόβιο token που χρησιμοποιείται μόνο για την έκδοση νέου access token. |
| Refresh token rotation | Κυκλική εναλλαγή διακριτικών | Μηχανισμός ασφαλείας όπου κάθε ανανέωση παράγει νέο μοναδικό refresh token. |
| Replay attack | Επίθεση επανάληψης | Επίθεση που επαναχρησιμοποιεί ένα έγκυρο μήνυμα ή token που υποκλάπηκε. |
| Repository pattern | Πρότυπο αποθετηρίου | Μοτίβο σχεδίασης που διαμεσολαβεί μεταξύ επιχειρησιακού επιπέδου και πηγών δεδομένων. |
| Reverse proxy | Αντίστροφος διαμεσολαβητής | Server που δέχεται τα αιτήματα των clients και τα προωθεί σε εσωτερικές υπηρεσίες (εδώ το nginx). |
| Route | Διαδρομή | Η διεύθυνση (path) του API στην οποία αντιστοιχεί ένα τμήμα κώδικα. |
| Runtime | Περιβάλλον εκτέλεσης | Το περιβάλλον και η χρονική φάση κατά την οποία εκτελείται ένα πρόγραμμα. |
| Schema | Σχήμα βάσης | Χώρος ονομάτων μέσα σε μια βάση PostgreSQL με τους δικούς του πίνακες. |
| Schema-per-tenant | Σχήμα ανά μισθωτή | Μοντέλο απομόνωσης όπου κάθε πελάτης διαθέτει ξεχωριστό schema στην ίδια βάση. |
| Screen pinning | Καρφίτσωμα οθόνης | Λειτουργία του Android που διατηρεί μία εφαρμογή στην οθόνη μέχρι να την αποδεσμεύσει ο χρήστης. |
| Script | Σενάριο εντολών | Αρχείο με εντολές που εκτελούνται αυτόματα με τη σειρά. |
| Seed data | Αρχικά δεδομένα | Δεδομένα επίδειξης που φορτώνονται στη βάση για δοκιμή του συστήματος. |
| Self check-in | Αυτόνομη άφιξη | Ο επισκέπτης εισέρχεται στο κατάλυμα χωρίς να συναντήσει τον ιδιοκτήτη. |
| Server | Διακομιστής | Υπολογιστής ή πρόγραμμα που δέχεται και εξυπηρετεί αιτήματα από clients. |
| Server-Sent Events | Συμβάντα από τον διακομιστή | Μηχανισμός με τον οποίο ο server στέλνει ενημερώσεις στον browser μέσω μιας ανοιχτής σύνδεσης HTTP. |
| Session | Συνεδρία | Το χρονικό διάστημα κατά το οποίο ένας χρήστης παραμένει συνδεδεμένος. |
| Shared schema | Κοινό σχήμα | Μοντέλο όπου όλοι οι tenants μοιράζονται τους ίδιους πίνακες και διακρίνονται με μια στήλη αναγνωριστικού. |
| Soft delete | Λογική διαγραφή | Σημείωση εγγραφής ως ανενεργής χωρίς φυσική διαγραφή της από τον πίνακα. |
| Source set | Σύνολο πηγαίου κώδικα | Φάκελος κώδικα ενός module για συγκεκριμένη πλατφόρμα, π.χ. commonMain ή jvmMain. |
| State machine | Μηχανή καταστάσεων | Υπολογιστικό μοντέλο που ελέγχει τις επιτρεπόμενες μεταβάσεις καταστάσεων παραγγελίας. |
| Stateless | Χωρίς κατάσταση | Αρχιτεκτονική όπου κάθε αίτημα περιέχει όλες τις απαραίτητες πληροφορίες εκτέλεσης. |
| Tablet | Ταμπλέτα | Φορητή συσκευή με οθόνη αφής· εδώ η συσκευή kiosk μέσα στο κατάλυμα. |
| Tech stack | Τεχνολογίες του έργου | Το σύνολο των γλωσσών, βιβλιοθηκών και εργαλείων που χρησιμοποιεί ένα έργο. |
| Tenant | Μισθωτής | Πελάτης της πλατφόρμας με δικά του, απομονωμένα δεδομένα· εδώ κάθε ιδιοκτήτης. |
| Token | Διακριτικό ασφαλείας | Κρυπτογραφικό σύμβολο που πιστοποιεί την ταυτότητα και τα δικαιώματα ενός χρήστη. |
| Trade-off | Αντιστάθμισμα | Το κόστος ή ο περιορισμός που συνοδεύει μια σχεδιαστική επιλογή. |
| Transaction | Συναλλαγή (βάσης δεδομένων) | Σύνολο λειτουργιών στη βάση που εφαρμόζονται είτε όλες είτε καμία. |
| Type safety | Ασφάλεια τύπων | Ο compiler εντοπίζει ασυμβατότητες τύπων πριν από την εκτέλεση. |
| Use case | Περίπτωση χρήσης | Περιγραφή μιας αλληλεπίδρασης ενός χρήστη με το σύστημα για την επίτευξη ενός στόχου. |
| ViewModel | Μοντέλο προβολής | Κλάση που διατηρεί την κατάσταση μιας οθόνης ανεξάρτητα από τη διεπαφή. |
| Volume | Τόμος δεδομένων (Docker) | Μόνιμος χώρος αποθήκευσης που διατηρείται όταν διαγράφεται το container. |
| Web panel | Διαδικτυακός πίνακας διαχείρισης | Η εφαρμογή web με την οποία διαχειριστές και ιδιοκτήτες διαχειρίζονται το σύστημα. |
| Webhook | Ειδοποίηση μέσω HTTP | Αίτημα HTTP που στέλνει μια εξωτερική υπηρεσία όταν συμβεί ένα γεγονός. |
| WebSocket | Αμφίδρομη σύνδεση web | Πρωτόκολλο για μόνιμη, αμφίδρομη σύνδεση μεταξύ browser και server. |
