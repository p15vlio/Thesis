## Abstract

This thesis presents the design and implementation of a digital ordering and services system for short-term rental accommodations. The system is implemented as a multi-tenant SaaS platform, featuring an in-room kiosk application running on an Android tablet as the primary guest touchpoint. Guests can browse the product catalog, place orders, and complete payments directly on the device, without installing any application or creating an account. Accommodation owners manage their properties, product catalog, and incoming orders through a dedicated web panel, while the platform simultaneously serves multiple independent owners with complete data isolation.

The system architecture is grounded in Clean Architecture and the Port/Adapter pattern, keeping core business logic strictly decoupled from infrastructure and external services. The entire codebase is developed in Kotlin, leveraging Kotlin Multiplatform (KMP) to share the domain model and DTOs across the backend (JVM), the Android kiosk application, and the web panel (WebAssembly). The backend was developed using Ktor and JetBrains Exposed, while the database employs a schema-per-tenant strategy in PostgreSQL to enforce structural isolation at the database engine level. The web panel was implemented using Compose Multiplatform targeting wasmJs.

The outcomes of this work include a fully functional, integrated prototype covering the hierarchy platform → owner → property → device → guest. The system incorporates role-based JWT authentication, automated device provisioning via QR code, an order state machine, external delivery and payment integration via emulated adapters, and platform-level audit logging. The thesis empirically demonstrates that Kotlin, through KMP, provides a robust and coherent foundation for engineering modern, multi-layered distributed software systems.

**Keywords:** multi-tenant SaaS, kiosk, Android, Kotlin Multiplatform, Clean Architecture, REST API, PostgreSQL
