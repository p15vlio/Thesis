Το **Guest Desk** είναι μια multi-tenant πλατφόρμα ψηφιακών παραγγελιών και υπηρεσιών για καταλύματα βραχυχρόνιας μίσθωσης. Ένα tablet μέσα στο κατάλυμα λειτουργεί ως σημείο εξυπηρέτησης: εκεί ο επισκέπτης βρίσκει τις πληροφορίες της διαμονής του, παραγγέλνει και πληρώνει, χωρίς εφαρμογή ή λογαριασμό. Το σύστημα αποτελείται από ένα κεντρικό backend, ένα web panel διαχείρισης και την εφαρμογή kiosk, γραμμένα όλα σε Kotlin με κοινό μοντέλο δεδομένων. Τα δεδομένα κάθε ιδιοκτήτη τηρούνται σε ξεχωριστό schema της βάσης.

Το έργο αποτελεί το πρακτικό μέρος πτυχιακής εργασίας στο Τμήμα Πληροφορικής του Ιονίου Πανεπιστημίου. Το κείμενο της εργασίας βρίσκεται στην ενότητα [Πτυχιακή Εργασία](/report)· αυτή η σελίδα είναι μια σύντομη ξενάγηση.

![Ο πίνακας ελέγχου του ιδιοκτήτη στο web panel](/media/web-owner-dashboard.png)

## Ποιοι το χρησιμοποιούν

| Ρόλος | Χρησιμοποιεί | Τι κάνει |
|---|---|---|
| **Διαχειριστής πλατφόρμας** | Web panel | Δημιουργεί ιδιοκτήτες (τα στοιχεία της εταιρείας συμπληρώνονται από το δημόσιο εταιρικό μητρώο), επαναφέρει κωδικούς πρόσβασης, ρυθμίζει την αποστολή email (SMTP) και το κλειδί του μητρώου, διαβάζει το audit log |
| **Ιδιοκτήτης** | Web panel | Προσθέτει καταλύματα και συσκευές kiosk, δημιουργεί τον κατάλογο προϊόντων (ή τον εισάγει από πλατφόρμα διανομής), συνδέει πλατφόρμες διανομής, παρακολουθεί και ενημερώνει παραγγελίες |
| **Επισκέπτης** | Tablet kiosk | Περιηγείται στο κατάστημα του καταλύματος και στα εστιατόρια των συνδεδεμένων πλατφορμών, ολοκληρώνει την παραγγελία με κάρτα, παρακολουθεί την κατάστασή της, διαβάζει τις πληροφορίες διαμονής |

## Τι περιλαμβάνει

| Module | Τεχνολογία | Σκοπός |
|---|---|---|
| `:backend` | Ktor, Exposed, PostgreSQL | REST API (65 endpoints), multi-tenancy, παραγγελίες, ενσωματώσεις |
| `:owner-web` | Compose Multiplatform, Kotlin/Wasm | Web panel για διαχειριστές και ιδιοκτήτες |
| `:app` | Jetpack Compose, Android | Εφαρμογή kiosk για το tablet |
| `:domain`, `:data` | Kotlin Multiplatform | Οντότητες, ports και DTOs που μοιράζονται τα τρία modules εφαρμογής |

Όλος ο κώδικας είναι γραμμένος σε Kotlin, σε ένα ενιαίο αποθετήριο: περίπου 22.500 γραμμές σε 268 αρχεία. Επειδή οι οντότητες και τα DTOs είναι κοινός κώδικας, η αλλαγή ενός πεδίου ελέγχεται από τον compiler ταυτόχρονα στο backend, στο web panel και στην εφαρμογή kiosk.

## Πραγματικές και προσομοιωμένες ενσωματώσεις

| Πραγματικές υπηρεσίες | Προσομοιωμένες υπηρεσίες |
|---|---|
| Αποστολή email μέσω SMTP (μηνύματα καλωσορίσματος, αποδείξεις) | Ο φορέας πληρωμών |
| Αναζήτηση στοιχείων εταιρείας με ΑΦΜ σε δημόσιο εταιρικό μητρώο | Οι πλατφόρμες διανομής φαγητού |
| Αναζήτηση διευθύνσεων σε δημόσια υπηρεσία γεωκωδικοποίησης | |

Η χρέωση, η έγκριση και η επιστροφή μιας πληρωμής είναι αρμοδιότητα του φορέα πληρωμών· το σύστημα απλώς τον καλεί. Κάθε εξωτερική υπηρεσία βρίσκεται πίσω από ένα port interface στο module `:domain`, οπότε η αντικατάσταση ενός προσομοιωμένου adapter με πραγματικό δεν απαιτεί αλλαγές στην επιχειρησιακή λογική ([Αρχιτεκτονική](/overview/architecture)).
